Photo checks

Craig can check listing photos for reused images and watermarks using your own Google Cloud Vision key. Set one up in five steps:

  1. Create or choose a Google Cloud project
  2. Turn on billing for that project
  3. Enable the Cloud Vision API
  4. Create an API key
  5. Restrict the key to the Cloud Vision API and set a budget alert

Your key is stored only in this browser profile and is sent only to Google. Listing text never leaves your computer.
